# 合成时序扰动 GRN 实验协议

这是研究协议及其可测试的软件骨架，不是已经运行完的实验。**当前阶段不生成 4 张开发网络、20 张盲测网络或正式快照数据。** 单元测试只使用极小的人工测试夹具。主实验若启动，须先在开发网络冻结本文件末尾的阈值、种子和模型选择规则，再让独立评分侧生成并封存盲测信息。

## 研究问题

本研究利用隐藏真实 GRN（基因调控网络）与隐藏动力学的合成时序扰动系统，区分两个先验条件不同的问题：**不知道真实动力学形式时，能否从有限快照学习有效扰动传播；知道正确动力学架构但不知道参数时，新增实验能否缩小相容参数范围。** 两部分使用相同的合成网络、扰动协议、预算和封存测试，但必须分别得出结论。

### 问题一：未知动力学形式下的扰动传播学习

学习器既不知道真实方程的解析形式，**也不知道它属于哪些候选生成函数族**。模拟器内部使用隐藏的 sigmoid（S 形响应）或 Hill（希尔响应）动力学生成数据；它们只是检验泛化能力的两种隐藏环境，不能作为学习器可选择的两个候选方程。学习器仅能使用按协议开放的靶点、名义强度、采样时间以及不配对 RNA（核糖核酸）快照，在开发阶段预先登记的通用建模假设下学习有效动力学

\[
\widehat F_{\phi}(\mathbf x,\mathbf u),
\]

其中 \(\mathbf x\) 为 RNA 状态，\(\mathbf u\) 为持续外部扰动。真实方程 \(F\)、GRN、边权 \(A\)、真实局部导数 \(J(\mathbf x)\) 与靶点效率 \(\rho_q\) 只保留在模拟器和评分侧，均不交给主学习过程。开发网络上的真实速度/导数诊断只检验预登记学习器的表达能力，不能用来为各生成家族选择专属模型或初始化正式训练参数。

核心问题是：**未知真实动力学形式及其候选族时，有限的不配对时序扰动快照能否支持可泛化的有效传播动力学学习？** 分别评价未见条件下的 RNA 响应、GRN 有向边与符号、局部导数以及长期行为。好的表达量预测不能单独证明恢复了正确机制。

### 问题二：已知方程架构下的参数可辨识性与主动实验设计

这一部分有意改变先验：学习器获得与生成系统一致的函数架构 \(F\)（例如调控项如何组合、扰动作用于何处），但不知道真实 GRN 中哪些允许的边存在、边权、其他动力学参数或靶点效率。**已知方程架构不等于已知网络。**对于

\[
\frac{d\mathbf x}{dt}=F(\mathbf x,\mathbf u;\boldsymbol\theta),
\]

\(\boldsymbol\theta\) 可以包含调控、产生、降解、非线性响应和扰动效率参数。这里的“已知形式”是**有利先验对照**，不是把真实参数或 GRN 泄露给学习器，也不保证数值优化必然给出性能上界。

研究对象不只是一个最优估计，而是第 \(k\) 轮已开放条件集合 \(\mathcal C_k\) 下的相容参数集。为确保“新增实验排除解释”的说法严格成立，按开发阶段冻结的逐条件差异度量 \(D_c\) 与容差 \(\epsilon_c\) 定义

\[
\Theta_k=\bigcap_{c\in\mathcal C_k}
\left\{\boldsymbol\theta\in\Theta_{\mathrm{adm}}:
D_c\!\left(\mathcal M_c(\boldsymbol\theta),\widehat P_c\right)
\leq\epsilon_c\right\}.
\]

\(\widehat P_c\) 是条件 \(c\) 的不配对观测分布；前两个重复用于参数拟合，第三个重复可按预定规则检验相容性，不参与参数梯度拟合。由于每轮只增加约束，才有 \(\Theta_{k+1}\subseteq\Theta_k\)。若改用随新增样本重新平均的总损失及固定容差，这种嵌套性就不能自动保证。

主动方法在相同的 90 条候选条件与 12 次预算下，选择新的“靶点 × 强度 × 采样时间”，目标是排除原本相容的参数解释、收缩参数范围，并减少这些解释之间的预测分歧；与冻结的随机和均匀规则比较。未采靶点的效率只能在预设范围内变化，不能提前以该靶点的响应估计效率。核心问题是：**已知正确方程架构但参数未知时，哪些新增实验最有助于消除参数退化、提高实际可辨识性？** 分别报告参数集合或可辨识参数组合的收缩、真实参数恢复、局部动力学误差及未见条件预测。若同时允许不同的离散边结构，应分开报告结构歧义与每种结构内的参数不确定性。对于在方程中只能以乘积等形式出现的参数，必须先固定尺度或报告等价类；不能把原始参数的不可唯一恢复误称为实验设计失败。

### 两个问题如何分别得出结论

问题一检验 \(F\) 未知时的动力学学习与发现；问题二检验 \(F\) 已知、\(\boldsymbol\theta\) 未知时的系统辨识与主动实验设计。二者共享数据设计，但不能用同一个分数互相代替。结果分为三个层面：未见靶点/强度/时间及组合条件的**预测**；GRN 边、符号、局部导数、参数组合和单独求解稳态的**机制恢复**；固定预算下竞争网络歧义或相容参数范围的**实验设计收益**。只有模拟器定义的 RNA 层有效调控可称“真值”，不等同于真实生物系统中的直接分子结合或完整生物物理机制。

本仓库实现的是**独立可控的合成 ODE（常微分方程）模拟器**，不是直接调用 scMultiSim。scMultiSim 可以作为后续外部压力测试或数据生成层扩展，但不能在不核对其扰动语义、真实 GRN 的可取性和时序机制前，直接替换这里的两个生成函数。

## 固定设计

每张网络 24 个基因、16 个可扰动调控者、40 条有符号有向边；每目标入度至多 3、每调控者出度至多 5、每非调控基因至少有一条入边，含链、前馈及正负反馈基序。4 张网络用于开发，20 张独立网络用于盲测；每张网络配对使用 sigmoid（S 形响应）与 Hill（希尔响应）两个非负产生速率函数。网络输入权重 `A[target, regulator]`、局部导数 `J(x)` 和扰动响应是三种不同对象，分别保存和评分。

扰动一律于 `t=0+` 启动并持续；`t>0` 是采样时间。`t=0` 只是一份共同的扰动前基线，不是靶点响应。每靶点隐藏效率 `rho_q` 在所有名义强度、时间和重复中固定，实际抑制比例为 `rho_q * d`。生成器取值在 `[0.7, 1]`；学习/选样使用事先规定的保守范围 `[0.5, 1]`，不读取真实值。新靶点在取得响应前没有已估计的效率，只能做范围敏感性分析。

16 个调控者按 6/6/2/2 划分：初始训练 6、主动候选 6、固定验证 2、最终测试 2。初始网格有 36 个条件；候选网格有 90 个；主动、随机、均匀策略共享同一初始数据与候选池，各付费选择 12 个**不重复**条件，但可以选择不同条件。每个已采靶向条件有 3 个重复，默认每重复 128 个扰动细胞和 128 个匹配对照细胞。前两个重复拟合参数，第三个只用于逐轮等拟合检验。各时间、各处理臂独立采样，不给跨时间或扰动/对照细胞配对。共同 `t=0` 基线只采、计费一次。

验证固定为验证靶点上的 `d={0.3,0.7}`、`t={0.25,1,4}`，在第 12 次采样后开放。`t={2,8}` 的扰动组及其实测对照一直封存到模型选择和所有最终预测锁定。最终分层测试分别为新靶点、新强度、`t=2` 插值、`t=8` 外推及组合挑战；这些分层共享网络和部分靶点，**不是独立的四组统计样本**。`t=8` 不是稳态，稳态另行数值求解。

## 软件模块及信息边界

- `simulation.py`：预设 GRN、两类隐藏动力学、真实局部导数、单独的稳态求解与诊断。只在模拟器/评分侧使用。
- `observations.py`：条件确定性的独立快照采样；真值和隐藏效率不随 `ReplicatedSnapshot` 交给学习器。早期对照只随付费靶向条件获得，不额外免费释放。
- `protocol.py`：6/6/2/2 网格、12 次预算、拟合/检验重复、验证及最终测试的开放门禁。`workflow.py` 记录三策略分支、验证选择和预测锁定顺序；其中的生成家族标签是**评分侧元数据**，不得传给问题一的学习器。
- `learning.py`：问题一的通用稀疏有符号 ODE 学习器，不接收生成家族标签、真实方程或参数，但确实预设单调调控、加性输入等建模归纳偏置。主训练只消费已开放的**不配对快照**。开发期的真速度/导数表达能力诊断使用模型深拷贝，不把真值拟合参数带入主训练。未知靶点的默认效率只是先验中点；敏感性包络不是已校准的置信区间。
- `ambiguity.py` 与 `selection.py`：现阶段实现的是**竞争边结构**的辅助分析：用第三重复筛选不同结构，并在未知效率下选择能区分结构的条件；无合格竞争结构时回退均匀顺序。它们**不是**问题二要求的相容参数集构建或参数导向主动选样。
- `baselines.py`：终点响应、黑盒动力学，以及已知精确方程形式但未知所有参数/网络/效率的模型。最后一种目前只有点估计训练接口，是问题二的起点，不是未经训练就成立的数学性能上界。
- `metrics.py`：不配对分布误差、对照校正响应误差、边存在性 AP（平均精确率）、符号 F1、局部导数与稳态误差、区间覆盖率、固定登记**边结构**的排除比例，以及以 20 张网络为单位保留双生成形式配对的自助法区间；尚无参数集收缩指标。细胞不能冒充独立网络样本。

`BlindStore` 的 Python 私有字段和方法门禁只是防**意外**泄漏的程序约定，不是对能读取同一进程内存和磁盘的研究者/代理的安全隔离。正式盲测应把原始候选池、测试快照和真值放在独立评分进程或受限账户；学习训练进程只接收已开放快照。当前仓库还没有该跨进程评分服务，因此**不应声称已经执行可信盲测**。

## 三端分工与代码同步

- **Mac：**设计 GRN、审阅代码和结果、发起及管理远程任务；不承担正式批量计算。
- **Windows 笔记本：**以 ChatGPT Windows 桌面应用为 Codex Remote（远程连接）主机，把 Codex 的*代理运行环境*切至 Ubuntu/WSL2；RTX 4070 用于小规模试运行、环境兼容性和显存检查。终端选用 WSL 与代理实际运行于 WSL 是两个独立设置。Windows 需要开机、联网且桌面应用运行，远程任务才可访问。
- **云端 Linux：**由 Mac 通过 SSH（安全外壳远程登录）添加远程项目，承担正式批量实验。云服务器无需 ChatGPT 桌面应用，但需普通用户、SSH 密钥、可在登录 shell 找到的 `codex` 命令以及相应计算环境。跨网络访问应通过 VPN（虚拟专用网络）或网状网络，不直接公开 Codex 服务端口。

三端使用**同一个私有 Git 仓库同步代码和版本记录**，实验数据、结果和检查点另行存储，不靠同一 ChatGPT 账号同步本地文件。若使用 Codex 的任务交接，目标主机还须保存同一 Git 仓库的项目。Mac 本地 `GRN` 项目使用私有 Git 远端保存代码；Windows 与云端项目仍需单独配置。不要把这份部署设计误读为三端均已连接或可启动正式实验。

接入顺序：先在 Windows 设置代理运行于 WSL、重启应用并配对 Remote，用一个临时 WSL 项目只读检查 `pwd` 和 `/usr/lib/wsl/lib/nvidia-smi`；Mac 代码稳定后建立私有 Git 远程仓库、提交并在 Windows 的 `~/code/GRN` 克隆，随后保存真正的 `GRN` 项目；最后购置/配置云服务器、验证普通用户 SSH 登录，再添加云端项目。这样无需在私有仓库建立前先创建另一个同名但历史不同的 Windows 仓库。

官方设置参考：[Windows 应用的 WSL 运行环境](https://learn.chatgpt.com/docs/windows/windows-app)、[Codex Remote、SSH 项目与任务交接](https://learn.chatgpt.com/docs/remote-connections)。

## 当前可做的验证

在本机的已有环境中：

```bash
.venv/bin/python -m pytest -q
```

在 Windows 的 Ubuntu/WSL2 中克隆同一私有 Git 仓库后，可创建独立 Python 环境、安装 `.[dev]` 并运行相同测试。请把仓库放在 WSL2 的 Linux 文件系统（例如 `~/code/GRN`），避免 `/mnt/c` 路径带来的 I/O 与权限问题。正式 24 网络实验尚无自动启动命令；不要把单元测试理解为已经完成性能评价。

## 正式实验前仍须冻结

1. 4 张开发网络上确定主种子、有限精度步长及非负性、稳态、弱边的数值通过阈值。若某家族缩边导致实际局部作用低于门槛，应重设模拟器范围或报告弱边分层，而不能事后删除不利盲测图。
2. 对两个生成家族分别运行隔离的真实速度/局部导数表达能力诊断；只有通过后才能解释不配对快照学习结果。确定诊断的状态分布、容差和失败处置。
3. 固定竞争结构提议数量、检验重复的分布/效应容差、最小实际局部作用，以及重复采样和多次训练的次数；三策略使用同一份初始登记结构。等拟合结论只对这些约定的模型类、噪声容忍度和数据预算成立。
4. 固定选样效率网格、模型选择分数、边阈值、预测区间的构造/校准规则，以及网络级配对统计方案。当前效率包络仅是敏感性范围，不能直接当成名义 95% 置信区间。
5. 为问题二另行设计**参数相容集**或其预登记的有限近似、参数范围/预测分歧指标及主动选样准则；在开发网络固定参数归一化或明确可辨识组合。现有已知形式模型只会拟合一个点，现有边结构登记不能充当参数集收缩证据。
6. 实现评分进程与磁盘权限隔离、完整训练/主动循环编排、断点恢复和结果摘要后，才启动正式生成与盲测。项目内 `data/`、`results/`、`checkpoints/` 默认不纳入 Git。

方案的相关先例：[Steiert 等（2012）](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0040052) 是已知网络下参数重拟合及信息性实验选择；[Mélykúti 等（2010）](https://link.springer.com/article/10.1186/1752-0509-4-38) 更直接对应区分竞争网络模型。本研究不把“主动区分网络”本身称为首创。
