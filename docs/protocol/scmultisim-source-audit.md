## 直接从 1.8.0 源码确认的行为

| 位置 | 已读取的行为 | 对本项目的约束 |
| --- | --- | --- |
| `R/1_main.R` 的 `sim_true_counts` | 接收 `options` 和 `return_summarized_exp` | 不编造独立的持续 KD 或任意采样时间接口 |
| `R/2_sim.R` 的 `.matchParamsDen` | 保存历史值、按合并秩重新抽取密度匹配值 | 不能在每个反馈步直接调用并声称产生率只由当前状态决定 |
| `R/2_sim.R` 的产生率计算 | 背景输入叠加 GRN 作用，再经密度映射、`10^` 和缩放 | 不把已含 GRN 的最终 `s` 再当背景，重复加入网络 |
| `R/2_sim.R` 的 `gen_1branch` | 含双态启动子、未剪接/已剪接层；内部时间与细胞数、基因相关步长关联 | 原生发育序列不能直接解释为本实验独立的干预经过时间 |
| `R/2_sim.R` 的状态编码 | 原生启动子 `1=on`、`2=off` | 新接口若用 `G∈{0,1}`，必须显式转换并测试 |
| `R/2_sim.R` 的 `beta_genes/d_genes` | 使用正态抽样的剪接与降解参数 | 新内核参数入口须独立拒绝非正速率，不能假定所有抽样自动有效 |
| `R/2_sim.R` 的多个内部函数 | 可见 `set.seed` 调用被注释 | 随机流由项目明确登记和管理，不能只依赖内部函数名中的 seed |
| `R/6_technoise.R` | RNA 观测噪声函数与整体噪声包装分别存在 | 主实验不调用技术噪声；RNA-only 压力测试另行核实接口与输入 |

这些是有限范围的源码核查，不是整个包的正确性证明，也不推定任意 GRN 或参数配置都可成功运行。

## 新增、替换和保留

保留的机制：双态启动子、产生／剪接／降解层次，以及 GRN 改变产生率的思路。

本项目新增或替换的机制：冻结的公共正映射 `g` 与单个公共 `K`、持续产生项 KD、事件时间抽样、分段解析 RNA 推进、同步反馈数值校准、独立条件初态与快照、平稳分布采样和封存接口。**尚未实现和验收**；论文中应称“基于 scMultiSim 机制的持续扰动扩展”，不能称原包原生功能或逐值等价实现。

Windows 首个工作包：

1. 记录 R、scMultiSim、依赖与项目版本，取得基线归档并核对哈希。
2. 用独立四基因夹具实现完整状态和参数入口；从无边开始，再加入激活／抑制边。
3. 验证固定产生段解析解、`β=γ` 极限、正速率、非负状态、持续 KD 比例与暂停恢复。
4. 校准反馈分辨率和长期分布，再接入快照／封存接口。通过前不生成正式 20 网络、不开始主模型训练。

准确的验收清单见 [实施与门禁清单](implementation-checklist.md)。本文件没有将任何开发期 `null` 设为已通过。
