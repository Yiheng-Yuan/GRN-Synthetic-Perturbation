# 实验一原始目标的落实与结构验收要求

2026-10-29。**这是对实现偏离的纠正，不是用户更换研究问题。** 显式图开发模型、训练器、独立评分与Windows运行器现已编写并通过小型软件测试；真实64基因训练与GPU资源验收待执行。此前无图运行保留为黑盒神经动力学开发对照，不能计作本目标已完成。已实现架构、实际损失归约和执行说明见[显式图开发入口](../q1-explicit-graph.md)。

## 1. 原始目标与偏离证据

初始提交 `ba93890` 的 README 在问题一已明确要求：

> 分别评价未见条件下的 RNA 响应、GRN 有向边与符号、局部导数以及长期行为。好的表达量预测不能单独证明恢复了正确机制。

该版本的 `learning.py` 确实实现了可训练的基因对连续边矩阵。后来的 scMultiSim v1 文档将 Q1 主结论收窄为预测，并允许无法给出边分数时记“不适用”；实际 Q1 开发训练又使用没有图参数的全连接向量场。这是后续文档及实现的偏离，不能倒过来据此宣称原始需求没有图恢复。

二值 W、边权 H 与 Z=W⊙H 是明确的模型参数化要求；其具体表达被再次澄清，不等于“学习动力学并恢复 GRN”这个原目标发生变化。

历史证据：[初始 README](https://github.com/Yiheng-Yuan/GRN-Synthetic-Perturbation/blob/ba93890/README.md)、[初始结构化学习器](https://github.com/Yiheng-Yuan/GRN-Synthetic-Perturbation/blob/ba93890/src/grn_experiment/learning.py)、[纠偏前协议](https://github.com/Yiheng-Yuan/GRN-Synthetic-Perturbation/blob/78632a7/docs/protocol/scmultisim-v1.md)。

## 2. 不变的研究问题

**在不知道生成器的真实网络、边权、精确非线性函数及参数时，能否从时序扰动观测联合学习一个有显式有向 GRN 的非线性动力学模型，并分别验证预测、结构和动力学恢复？**

Neural ODE（神经常微分方程）负责用可学习函数表示变化率，并通过时间积分训练。未知的是实际非线性调控函数和参数，不代表没有任何模型结构。显式图、产生／消耗约束等必须作为公开建模假设登记；不把真实 A 或精确生成函数当候选答案提供给训练。

Q2 仍是给定生成器精确架构后的参数／结构相容性与主动实验问题；两题的区别不应被写成“Q1 无图、Q2 有图”。

## 3. 主模型的硬性结构要求

1. 显式保存可学习的边存在矩阵 W、边参数矩阵 H 和有效矩阵 Z，统一方向 `Z[i,j]` 表示 j→i。
2. `Z=W⊙H` 为逐元素相乘。W 的最终结构输出必须为 0／1；训练时使用什么梯度估计或连续松弛、如何离散化、如何选阈值须在开发侧登记。
3. W 必须控制真正的跨基因通路。对于 i 的更新函数，W[i,j]=0 应阻断 j 对 i 的直接作用；删除直接边不要求消除通过其他基因的间接作用。不能留下绕过门控的全连接核心。
4. 若保留显式 RNA 历史比较，历史通道也必须遵守图结构约束。历史只来自本次模型模拟；当前数据不提供真实单细胞历史。
5. 非线性函数由数据学习，不限定为生成器的精确指数映射或某个候选生成函数族。函数实现和尺度规范必须清楚，不能仅把旧 MLP 层权重改名为 H。
6. 生物学产生／消耗的框架及非负条件需要明确；若采用这样的分解，应保证产生项非负、消耗在零丰度时不将状态推负。把任意正负输出事后改名为产生／降解不算机制约束。
7. 若 H 的正负要解释为促进／抑制，须规定相应单调性或以明确定义的局部效应验证；任意非线性函数可改变输入符号含义。H 的幅度还需尺度规范，不能未经检查宣称为唯一可辨识的真实边强度。
8. 候选边仅能由公开的基因及实验信息决定，不得读取真实 A，也不得因真图有128边而强制输出128边。

由于生成器的 A 作用在未剪接 RNA 的产生项，成熟 RNA 真实变化又依赖隐藏 U/G，仅以 M 建立的闭合更新是有效近似。首个显式图开发实现采用M单状态、单调神经源／接收函数、加和的图输入、非负产生与正线性降解；不增加隐藏h或RNA历史。输出图对A只作开发基准，不能证明它是唯一或精确生成机制。**本文件不以存在显式矩阵代替可辨识性证明。**

## 4. 时序监督与损失要求

当前公共数据是独立细胞快照；生成器／评分侧另有真实图、参数及隐藏状态。真实图和参数的存在不等于可向学习器提供它们。

- 参数梯度通过模型的时间积分及损失反向传播；这与“相邻观测直接作差得到某个细胞的速度”是不同概念。
- 不配对数据可在各时间点比较预测与实测群体；不得把 t_k 的第 n 个细胞和 t_{k+1} 的第 n 个细胞拼成轨迹。群体均值差也不能冒充每个状态的真实速度标签。
- 若另行采用相邻真实状态监督，必须生成并登记真正配对的同细胞轨迹，明确测量与信息条件已变化；不能用现有快照伪造配对。
- 按用户 2026-10-29 的决定，删除独立的“处理减对照”响应差值损失，不设置 `lambda_response`，也不以扩大扰动效应作为优化目标。训练保留逐基因绝对表达及适当群体分布拟合，处理与对照均参与，并分别检查长期漂移。响应误差只作为独立评价指标保留。
- 图稀疏项直接针对 W 的边数或对应的期望边数，不能拿任意神经网络权重 L1 充当边数。
- 当前设计为 `L_expression + lambda_distribution * L_distribution + lambda_sparse * R(W)`：表达项系数固定为1作参考，比较同条件、同时间的逐基因处理／对照群体均值；分布项比较不配对群体，图项惩罚 W 的边数或期望边数。两项可调系数和表达缩放仅在训练靶点内部验证选择，目前尚未实测冻结。包含 `lambda_sparse=0` 的对照，避免以空图或删掉真实弱边换取表面稀疏。

响应差值误差并不奖励大效应：它原本惩罚的是预测与实测响应之差。删除它是用户选择简化预测目标，不是因为不同靶点的效应大小不同便使该误差无定义。若处理／对照预测的绝对误差分别为 eP、eC，响应误差就是 eP−eC，因此把两臂表达分别拟合正确也会约束响应；这不意味着有限预算下两种训练目标效果必然相同。

### 损失权重与评价标准的隔离

- 模型参数 W/H/非线性函数由训练数据优化；`lambda_distribution` 与 `lambda_sparse` 是实验超参数，不注册为模型可训练参数，也不允许梯度优化将不利项权重降为零。
- 表达项系数固定为1，仅用训练数据确定表达缩放，并明确表达／分布项按条件、时间和基因的归约方式，图项为期望边数之和。结合[四篇论文的权重与归约核查](q1-loss-literature.md)，下一轮诊断的起始候选为 `lambda_distribution=0.1`、`lambda_sparse=1e-4`；固定分布系数后比较 `lambda_sparse in {0,1e-5,1e-4,1e-3}`，共4组。选出候选后补一个 `lambda_distribution=0` 的消融对照。这替代上一版尚未运行的6组草案。具体数值均是本项目未验证的工程候选，不能称为四篇论文已验证的权重；图规模、表达缩放或损失归约改变时不能直接沿用。
- 表达项对已登记条件／时间／基因取平均，处理与对照平衡计入；分布项在同一固定缩放下比较不配对群体，其具体距离与归约必须随模型实现登记。二值图训练若用随机门控，稀疏项为 `sum P(W[i,j]=1)`；若用其他松弛，必须解释其与最终边数的关系。64个基因、排除自环时有4032条候选方向：系数 `1e-4` 对100条确定存在的边给出0.01罚值，对全部候选边给出0.4032罚值。这仅解释数值尺度，不规定恢复多少条边，也不证明该系数适用。
- RegVelo、D-SPIN、CLAMP 的相关稀疏项主要约束连续权重或局部作用幅度；Shen等（2021）的主要网络精简方法是删边后重训练。它们不直接给出本项目二值W边数惩罚的适用系数。尤其不得把普通神经网络权重衰减当作W的稀疏约束，也不因CLAMP使用响应差拟合而恢复用户已经删除的独立响应差损失。
- 在训练靶点内部预先按靶点整组划出开发验证部分，所有时间和重复随靶点同组；主训练仅用拟合部分更新参数。候选组数、预算、种子及选择规则在试跑前记录，不能根据已查看的16个留出靶点追加候选。
- 验证选择以预先规定的表达预测误差为主，另查对照与分布误差；不以带稀疏罚项的训练总损失比较不同权重。误差接近时是否优先更稀疏及其容差须先登记，不能在看到结果后改规则。真实 A 不用于本轮选权重。
- 选定权重、训练设置和模型选择规则后冻结，再对既定训练池重新拟合；最终封存测试不参与梯度、早停、阈值或权重选择。测试分别报告原始表达／分布／响应误差、边精确率与召回率、符号及长期行为，不用模型可调整的加权总损失充当唯一成绩。
- 旧16个留出靶点已查看，不能恢复成新的可信盲测。它们可保留开发对照；正式结果需要新的网络／封存数据及独立评分。
- 权重冻结只阻止通过改权重降低某项要求，不能证明结构可辨识。模型仍可能拟合快照却得到错误图，必须验收实际门控无绕过路径，并以独立真值评分暴露假边、漏边和空图。

## 5. 交付前必须通过的验收

- [ ] 模型真实参数／导出接口包含 W、H、Z，维度与方向正确，Z逐值等于W⊙H；最终 W 二值，掩码与训练状态有明确记录。
- [ ] 通过逐靶点的零门控、断边与直接作用检查，证明当前及历史通道均不存在绕过图的跨基因通路；间接作用与直接边分开解释。
- [ ] 数值推进可微，图参数与非线性参数有实际有效梯度；积分精度和非负性有对应验收，二值门控策略没有造成无梯度假训练。
- [ ] 与原黑盒模型、无响应和直接响应基线在同数据、同划分及可比预算下比较；先小规模诊断，再交付 GPU 训练。
- [ ] 训练完成后由独立评分侧比较显式 W 的有向边、调控符号、假边与漏边，另报 H／Z 的可比性与不可辨识范围；预测准确不能替代结构评分。
- [ ] 动力学变化率、局部效应和长期分布按状态及单位可比的定义单独评分；不得把成熟 RNA 代理导数自动当作产生率导数。
- [ ] 旧 16 个留出靶点已被查看，继续比较属于开发结果；正式优势需要新的网络／种子验证。真值在参数拟合和超参数选择中保持隔离。
- [ ] 运行文档、实际配置和正式门禁都反映显式图要求，再构建新镜像；旧无图模型通过测试不得被计作此主模型验收通过。

现有 `experiment_plan.py` 和 `configs/scmultisim-main.json` 的 Q1 latent 维度字段仍属于旧正式准备方案，不作为本显式图开发入口的准入依据；本入口由 `GraphConfig`、固定运行器和每次保存的 `run_plan.json` 登记，不能通过它绕过正式门禁。生成器机制、现有数据、Q2、预算与旧运行记录本轮不修改。无分布项消融、历史图模型、完整科学校准与正式配置同步尚未完成。
