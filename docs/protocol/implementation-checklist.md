- [ ] 新增 scMultiSim 派生内核、条件适配器和私有真值容器；只替换科学数据源，不复用旧 sigmoid/Hill 参数表或恒零占位预测器。保持 `Condition` / `ReplicatedSnapshot` / `BlindStore` 的数据边界，任何变更须测试。
- [ ] 定义一张网络的 `A,b,k_on,k_off,β,γ,ρ` 与 24 基因／16 调控者／40 有符号边规范；同网络各细胞共享参数，随机 `G(0),U(0),M(0)` 与后续事件不同。把全部 16 个 `ρ_q` 的允许域定为 `[0.6,1]`，真值和私有种子不进入学习接口。
- [ ] 在无反馈的开发参考上校准正值、实际输入域内单调递增的公共 `g` 与单个 `K`，导出可版本化、可重载的文件和哈希；验证输出始终为正且隔离单边局部作用与边符号一致。严禁借某张盲测网络的对照平稳结果重新校准。

## B. 四基因内核验收；未通过不扩大规模

四基因夹具只验证机制与辨识算法，不使用正式的 16 调控者、6/6/2/2、90 候选网格。至少含直接与经中介的竞争解释及无边阴性读出。

- [ ] 实现离散启动子事件的精确时间抽样；事件、反馈更新点和请求采样点均能正确分段。给定固定 `G` 与产生率时，U/M 按解析解推进，单独测试 `β=γ` 的稳定极限、非负性和质量单位。
- [ ] 把 KD 限定为 `t=0+` 起持续乘靶点**映射后实际产生率** `1−ρ_qd`。同一完整状态下检查该速率比；零剂量与对照只要求预定统计容差内同分布，不要求独立细胞逐值相同。
- [ ] 比较无边、一条激活边和一条抑制边的局部产生率差分符号；不要求多边网络的下游总 RNA 变化与某条直接边同号。
- [ ] 以 `τ=1/32,1/64,1/128,…` 逐次检查参考条件的分布统计量收敛并保存误差曲线；不引入另一个 Euler `h` 或中途整数截断。验收容差、最终 `τ` 在开发数据上定值，目前为 `null`。
- [ ] 不同随机初态与独立谱系窗口检验平稳**分布**；记录未证实平稳而不改称多稳态。`t=8` 独立于长期平稳采样。
- [ ] 同一配置/种子复跑逐值一致；不同条件调用顺序不改变结果。暂停/恢复检查点须包括模拟时钟、G/U/M、网络与条件参数、**已抽出的待发生启动子事件时间、当前分段保持的产生率、下一反馈更新时刻或相位、完整随机数生成器状态**；只存科学状态或初始 seed 不足以保证同一路径恢复。测试中断再恢复与不中断运行逐值一致，并留存失败样例。
- [ ] 四基因完整流程演练：初始快照 → 最小主动购入 → 验证开放 → 预测锁定 → 独立评分；此演练不冒充正式 24 基因结果。

## D. Q1：未知形式、M-only、不配对

- [ ] 实现条件化 latent ODE 的 48/96 隐维两个开发候选；共同 `t=0` 决定初始隐分布，不能用未来靶点或时间点修改该分布。剂量和基因局部目标掩码通过共享更新规则输入，确保未扰动过的 test 靶点不是未训练类别向量。
- [ ] 从初态采样后按条件推进，解码 M 群体；只以同条件的**非配对分布损失**及预定控制/基线损失训练，不写跨时间的伪单细胞序列。分布损失、权重及计数解码器在开发网络冻结。
- [ ] 加入匹配均值/终点型、直接 `P(M|q,d,t)`、参数规模相近的非 latent-ODE 对照；记录网络/目标掩码消融。真 G/U/速度只供独立开发能力诊断，不传给主训练。
- [ ] 输出五分层预测、长期结果（评分时才打开）、未见靶点效率范围敏感性；不把潜状态导数解释成真实 GRN 或马尔可夫恢复。

## E. Q2：完整随机前向与相容参数集

- [ ] 学习器前向保留随机 G/U/M，M-only 观测通过模拟或合适的边缘似然比较；不得将旧 `KnownFormRNAODE` 的 sigmoid/Hill 方程改名复用。
- [ ] 用四基因夹具依次放开有效 `A/ρ`、`b/γ`、`k_on/k_off/β`，最后尝试完整 `θ=(A,b,k_on,k_off,β,γ,ρ)`；每阶段记录运行时间、内存、真实参数/组合覆盖与结构区分能力。到 24 基因前先测开发网络资源上限；不可把优化失败记为科学上的不相容。
- [ ] 从首轮起固定含所有未采靶点 `ρ` 的参数域；同一 `θ` 必须解释全部已开放条件。逐条件距离/容差及有限样本、前向 Monte Carlo 校准在开发期冻结；轮次只追加约束，才报告相容集嵌套与竞争结构排除。新增粒子或重拟合搜索结果只报数值近似。
- [ ] 主动选择、随机、均匀从同一 90 条和相同 12 次预算运行。主动效用在未知效率范围内保守比较预测分歧；分开报告结构歧义、参数组合宽度、预测改善和误排真值的频率。
