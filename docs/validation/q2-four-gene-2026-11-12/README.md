# 问题二四基因真参数前向检查

2026-11-12 在 Mac CPU 上用现有 scMultiSim 派生随机内核运行 36.45 秒。复用四个抽象基因的开发夹具，其中一个隔离基因作为阴性读出。共同基线的两组独立初态通过开发平稳性判据，接受烧入时间为 48 个模拟时间单位。

## 设置

- 靶点 0、1，名义强度 0.7，开发时点 1 和 4，另设留出时点 2。每个条件的扰动和对照各有三次独立重复，每重复每臂 128 个细胞。
- 观测侧只使用成熟 RNA 计数。评分侧用真参数从独立随机流生成两次预测重复，计算处理减对照的均值响应。以观测侧第三重复评分，同时报告观测侧前两重复对第三重复的误差和零响应基线。
- 此处为真参数前向参照。参数估计、竞争结构筛选、主动选样均待开展。

## 结果

| 范围 | 评分对象 | 真参数独立模拟 RMSE | 零响应 RMSE |
| --- | --- | ---: | ---: |
| 开发时点 1 和 4 | 直接靶点 | 0.4281 | 2.6077 |
| 开发时点 1 和 4 | 一跳下游 | 0.1469 | 0.0973 |
| 留出时点 2 | 直接靶点 | 0.5199 | 2.2351 |
| 留出时点 2 | 一跳下游 | 0.7376 | 0.4360 |
| 留出时点 2 | 隔离阴性读出 | 0.3137 | 0.2978 |

留出的一跳评分只有 3 个条件—基因组合。直接靶点的响应清楚；这一张图、一个种子和 128 个细胞每重复的设置尚未建立可用的一跳信号。真参数前向模拟与观测重复均含有限样本波动。下一步分别增加模拟预测样本和观测重复做校准，先确认可区分的响应，再拟合边权和扰动效率。
