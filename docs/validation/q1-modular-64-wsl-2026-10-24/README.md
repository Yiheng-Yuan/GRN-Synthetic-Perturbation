# 64 基因 Q1：Windows／WSL 训练结果与复核

审阅日期：2026-10-24。结果包内文件时间为 2026-10-23。

**结论：4800 次更新完整完成，数据、源码、模型和评分一致；但当前模型整体未超过“仅靶点变化迁移”基线，尚无非靶基因响应预测收益，不能宣称恢复了传播动力学或 GRN。** 本页记录开发结果，不是正式网络盲测报告。

## 1. 实际运行了什么

- 一张开发网络：64 基因、48 个可扰动调控者、128 条有符号有向边，六个模块、少量桥接和四个孤立基因。
- RNA 生成前登记 32 个训练靶点／16 个留出靶点。每次扰动后预测整个细胞的 64 基因表达，不只预测靶基因。
- 剂量 0.7，所有扰动在 t=0+ 启动并持续；采样时间 0.25、1、2、4、8、64，另有共同扰动前基线。t=64 是诊断支持的有限长期样本，不是逐细胞零导数标签。
- 训练只用训练靶点前两个重复；第三重复用于拟合后检查。留出靶点全部时间和三个重复不用于参数拟合。
- 未知方程形式的 latent Neural ODE（潜变量神经常微分方程）；29,250 个参数、隐藏宽度 64，不输入真实 GRN、隐藏效率、G/U 状态或生成方程。
- 固定 4800 次更新，六个时间各 800 次；有效每次更新 4 条件×64 细胞，按条件分批累积梯度。RK4 步长 0.25，学习率 0.001，随机种子 20261022。
- RTX 4070 Laptop GPU，Python 3.12.15、NumPy 2.5.3、PyTorch 2.14.0+cu126。GPU 训练日志约 4048.58 秒（67.48 分钟）；含 CPU 评分和数值复查共 4243.40 秒（70.72 分钟），不包含安装与传输。

长期显存检查峰值约 1.24 GiB，仅对应训练前的一次 t=64 更新，不能当作完整训练期间的实测峰值。

步长减半（0.25→0.125）复查覆盖 288 个条件：最大单预测值差 0.0010004，最大基因均值差 0.00038767，均通过预设容差。这只核对有限时间的积分误差，不证明渐近平稳、振荡或真实机制正确。

## 3. 未见靶点表现

下表为 16 个留出靶点×6 时间×3 重复的描述性平均，误差越小越好。共有 96 个不同留出条件、每模型 288 条评分记录；它们不是 288 个独立网络。

“无响应”基线始终保留共同基线表达；“仅靶点变化迁移”基线从训练靶点学习标准化的平均直接响应曲线，只改变被扰动基因，其他基因保持不变。

| 指标 | Neural ODE | 仅靶点变化迁移 | 无响应 |
| --- | ---: | ---: | ---: |
| 全基因响应 RMSE（均方根误差） | 0.360546 | 0.328875 | 0.410274 |
| 靶基因响应 MAE（平均绝对误差） | 0.808982 | 0.386531 | 1.760688 |
| 非靶基因响应 RMSE | 0.338701 | 0.325337 | 0.325337 |

| 扰动群体边际 Wasserstein-1（分布距离） | 0.855231 | 0.397773 | 0.413242 |

相对无响应，全基因响应误差降低约 12.12%；但相对仅靶点变化迁移，误差高约 9.63%。按每个靶点跨时间和重复平均，全基因响应没有任何一个靶点优于该迁移基线（0/16）。非靶基因不等于拓扑上的真实下游，边际分布距离也不直接评价基因协方差。

## 4. 本轮暴露的问题

**已观察到：** 未扰动对照也存在长期漂移；从保存的预测看，基线采样的全基因平均表达约 4.5896，模型对照预测在 t=64 约为 3.4192。训练靶点第三重复的表达均值误差也偏大，不能将全部失败归因于未见靶点。

训练损失有限但并非始终平稳。第 3108 次、t=64 的损失曾达 53.6581，随后恢复；该时间最后 10 次平均为 0.079595。不能用最终损失较低替代独立表达评分。

**待验证的解释：** 当前分布项使用 24 个固定随机方向衡量 64 维 log1p(RNA)，单独这一投影项不能约束全部方向；响应差值项也可能掩盖处理／对照的共同漂移。总目标另有原始计数响应约束，不能据此断言整个损失完全失效，也不能把这些线索写成已证明的唯一原因。

后续可以在保留当前版本和数据的前提下，分别比较逐基因表达约束、改进投影覆盖和对照稳定性约束。它们尚未实现或验证；本次上传不改变模型、不重训，不追加新图或新数据。选择后续设置应使用训练靶点内部验证，不根据这 16 个已查看的留出靶点反复挑版本。
