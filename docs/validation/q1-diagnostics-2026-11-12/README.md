# 问题一开发诊断与下一阶段

日期：2026-11-12。平台运行包括 64 基因合成开发数据的信号与模型诊断，以及六节点正对照。随后在 Mac CPU 上用同一六节点数据隔离边权、门控和其他动力学参数。两批结果用于开发排查，正式盲测仍待开展。

[下载实际执行的代码和完整验证报告](https://github.com/Yiheng-Yuan/GRN-Synthetic-Perturbation/releases/tag/q1-diagnostics-2026-11-12)。

## 已完成的运行

| 验证 | 实测结果 |
| --- | --- |
| 64 基因平台诊断 | 核验 27 个结果文件、192 个开发条件和四个拟合组共 960 次更新。一跳响应在重复间有可见信号，多跳均值效应接近对照参照。两种盲学组均导出 4,032 条边，真图有 128 条。内部留出靶点的固定真边支持组一跳误差 0.140586，零响应参照 0.140582。固定支持预测来自平台摘要。 |
| 六节点平台正对照 | 与学习器同一方程族，240 次更新，隐藏真图。导出 30 条边，其中 24 条是假边；留出 `t=6` 的一跳均方根误差 0.2785。 |
| 真参数复放 | 复建 24 个六节点条件，保存 55,296 个合成终点坐标；CPU 复放的最大绝对误差为 0。真参数的留出一跳误差 0.0192，零响应误差 0.2794。 |
| 单边拟合 | 固定真图和其他参数，只学 `0→1` 的边权。真值 +0.9，原始起点训练 960 步得到 +0.8546；有限差分与反向传播梯度一致。 |
| 固定真图，联合学六条边权 | 原始随机起点训练 960 步，六边符号全部正确，边权平均绝对误差 0.0124，留出一跳误差 0.0179。 |
| 固定真图，联合学边权和其余参数 | 从同一随机边权起点、其余参数从真值起步时，边权误差 0.5182，留出一跳误差 0.0237。全部参数从默认值起步时，留出一跳误差 0.2624。 |
| 隐藏真图，学习门控和边权 | 固定其他动力学参数，无惩罚和门控惩罚 `0.001` 各训练 960 步。两组均导出 30 条边，排名前六只命中 1 条真边，一跳误差约 0.261。 |
| 隐藏真图，直接拟合有效矩阵 Z | L1 系数 `0、0.01、0.1` 各训练 960 步。无惩罚组排名前六命中 4 条真边，一跳误差 0.2174；三组均导出 30 条边，其中 24 条是假边。 |

六节点实验以 `t=2,4,8` 的前两重复训练，以留出 `t=6` 的第三重复评价已见靶点的时间插值。排名前六使用评分侧的真边数量，仅用于诊断。真实边权与接收端响应斜率之间存在精确尺度等价，绝对边权和有效局部作用分别报告。已确认同一图可以对应等价参数；当前诊断没有建立不同有效图结构都能拟合好的证据。
