审查基线为 `22b2fd74e1a86e0228441f1df51c65e9677fcd2b`。本轮实现修复、登记评分规则，并分析已经返还的首张开发网络初始数据；未启动主模型训练或正式盲测。已交付的 `20261014-dev1` 镜像与归档保持其原始版本，本轮没有重新构建或发布镜像。

## 1. 三项意见如何落实

| 审核项 | 本轮处理 | 实际检查 |
| --- | --- | --- |
| M-only 速率交换等价 | 新增 `scmultisim_identifiability.py` 和完整证明／初态／参数域条件；原始、固定等价代表及不变量误差分别报告 | 向量场变换、完整轨迹、部分基因交换、非默认映射斜率、参数域与负 U 拒绝；A／ρ 的真实差异不能被豁免 |
| 映射冻结格式不一致 | 以 `PositiveMapping.to_config()/from_config()` 的 `positive_log_linear` 格式统一真实指数映射与正式校验器 | JSON 往返重建后的产生率和局部导数逐值一致；旧三字段参数 JSON 仍可读；不再接受另一函数族的查找表替身 |
| NumPy 整数靶点无法存检查点 | 初始化和恢复时，在合法性检查后统一为 Python 整数 | int32／int64／uint64 靶点均能经 JSON 恢复；非网格时刻恢复的 G/U/M 与直接运行逐值相同 |

等价关系不是通过改变生成器“修掉”的错误。我们保留 M-only 主实验，在评分层承认其能够区分的范围。每个基因只确定一次交换方式，对所有条件与参考状态共同使用；参数边界和初态合法性独立记录。完整细则见[参数等价规则](../protocol/parameter-equivalence.md)。

独立四基因复现使用三个剂量（0.3、0.7、0.9）、四个采样时间（0.125、0.5、2、8）与两种反馈间隔（1/16、1/32）：对应参数轨迹的 M 最大差异为 `1.4210854715202004e-14`，本次实例的整数计数相同；两套参数均符合所提供的七项边界。浮点状态靠近整数边界时，不声称所有可能初态都能逐位得到相同 floor 值。

另直接从受审 Git 提交加载旧实现，在四种正常 Python 整数／对照条件、每条件四个时间上比较新旧版本：16 个联合 G/U/M 状态和检查点全部逐值一致。这支持本轮映射序列化及靶点类型修复没有改变已测试的正常生成路径。旧数据不因这两处修复而自动失效；不同源码指纹仍不能混在同一生成目录续跑。

## 3. 返还数据的第一轮信号诊断

本轮分析实际读取共同基线和36个初始条件，共37个开放观测键，并验证所用38个文件的登记校验值。没有解码候选、验证、最终测试或长期 RNA 数组；没有向学习器提供真实 A 或图可达性标签。完整复现输入、方法、逐基因／条件汇总与文件哈希见[诊断报告](scmultisim-signal-2026-10-16/README.md)。

对照噪声参照是：对每个独立对照重复重采两组128细胞，重复2000次，取三重复平均差绝对值的95%分位数。标准化效应的计数标准差下限预设为1。它们都是当前开发描述；没有多重检验校正，不是显著性、FDR 或未来相容性通过阈值。

| 初始采样时间 | 两种剂量合计的直接靶点条件 | 高于探索性对照噪声参照 |
| --- | ---: | ---: |
| 0.25 | 12 | 0 |
| 1 | 12 | 10 |
| 4 | 12 | 12 |

在 `d=0.7,t=4`，直接靶基因的中位绝对 RNA 均值差为1.966计数，标准化效应中位数为1.136。可达下游只有34/558（6.09%）个基因×条件超过参照，不可达基因为13/270（4.81%）；下游在拟合／检验重复间的效应方向一致率为52.2%。

这份数据支持“晚时间有可见的直接靶向响应”，尚未证明它具有足以支持 GRN 传播恢复的下游信号。比例接近不能证明下游没有真实效应，也不能确定原因一定是取整、参数幅度或某一噪声机制。当前只有一张网络，不提供网络级功效或20网络泛化结论。

## 4. 根据实测结果调整实施顺序

1. 保留该批数据及旧指纹，作为软件流程与原开发参数的参照，不要求同学重复压缩项目或重新运行同一批次。
2. 在生成器开发侧区分“响应本身很弱”和“有限细胞／随机开关／取整使其难以观测”；补充连续 M 与整数 M 的对比、无边及单边夹具、同随机流数值诊断。这些真值诊断不进入主训练。
3. 开发校准时分开考察有效调控强度、启动子转换时间尺度与细胞预算，保留当前设置作基准。任何新参数范围均须记录且只在开发网络选择；不能为获得漂亮响应删除失败网络或仅放大已知可检出的边。
4. 候选设置在四张开发网络验证反馈间隔减半、边的实际局部作用和长期分布判据，再做小型学习能力诊断。现阶段尚未选择或宣称某组新参数已通过。
5. 最后冻结参数与评分规则，进入20张正式盲测。参数等价类代表不当作新的生物学先验，不要求主动策略消除精确不可区分的解释。

后续每次给计算同学交付镜像，都附宿主实际输出／日志绝对路径，以及仅打包结果和日志的命令；完整约定已加入[运行与回传说明](../scmultisim-runtime.md)。
