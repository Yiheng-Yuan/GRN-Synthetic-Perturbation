# Q1：64 基因稀疏模块化开发实验

2026-10-23，用户批准先增加网络规模和扰动覆盖，再判断是否需要修改学习器；随后选择 Mac 生成和审计，完整训练交给同学的 H200。旧 24 基因数据、模型与报告保留。本实验不是正式 20 网络盲测，也不是完整 GRN 恢复的已验证方案。

## 固定设计

- 64 基因、48 可扰动调控者、128 有符号有向边，密度为 128/(64×63)=3.17%；正负各 64 边，最大入度 3、最大出度 4。
- A–F 六个模块，每模块 8 调控者、2 输出基因、20 条内部边。各模块有不同的局部结构，包含调控环、前馈和正负反馈。桥接仅为 A→B 四条、B→C 两条、C→D 两条；E/F 独立。另有四个严格无入边、无出边的孤立基因。孤立基因仍有自身 RNA 产生与降解。
- 所有 48 个调控者有出边及经过不同节点的两跳路径；这是拓扑资格，不是信号可检测或模型可恢复的保证。模块为合成分组，不冒称真实生物功能模块。基因标签随机置换，模块身份不传给学习器。
- 网络种子 201、划分种子 20261023，先冻结拓扑再划分。A–D 各 5 训练／3 测试靶点，E/F 各 6／2，总计 32／16。按靶点整体留出全部时间和重复，不随机拆细胞。
- 所有扰动 t=0+ 启动并持续作用，d=0.7；每靶点未知效率跨时间、重复固定。采样 t={0.25,1,2,4,8,T_long}，共同扰动前基线只保存一次。
- 每条件 3 重复，每重复 128 处理细胞及独立匹配对照。每个条件、时间、重复、组均使用独立初态和轨迹随机流，不提供配对细胞轨迹。训练只使用训练靶点前两重复；第三重复仅在拟合后检查，16 测试靶点不进入参数拟合。
- 289 个 RNA 文件：一次基线＋48×6 条件，总计 221,568 个细胞观测；这是一个网络，不是 221,568 个独立网络样本。一次采样的细胞代表 64 基因全向量，不是只记录被扰动基因。

## 生成器边界与长期时间

继续使用基于 [scMultiSim 固定源码](https://github.com/ZhangLabGT/scMultiSim/blob/563c3b542ada289fb4d9789bb1bc944229e78699/R/2_sim.R)机制的**独立 Python 持续扰动扩展**，不调用 R，不是官方包的逐值复现。沿用 G 启动子、U 未剪接、M 成熟 RNA、正产生率映射和解析分段推进；没有新增另一套 ODE 数据生成器。旧 sigmoid/Hill 测试夹具不生成本轮数据。

生产项只在靶基因乘以 1−ρ_q d；调控反馈仍逐步更新。反馈网格 τ=1/32，不代表生物传播延迟。K 固定采用此前的开发参考 5.081441499910911，不根据这次测试响应重新调优。单纯扩大图不能保证下游信号增强。

先完成基线及全部 48 靶点的分布平稳诊断：两个独立起点、每起点 256 细胞，最短 16／最长 128，窗口 8，连续 3 个窗口；均值、方差和分布阈值与旧开发配置相同，不为通过而放宽。若任一失败，保留失败记录，不换种子、不生成冒充平稳的数据、不自动开始训练。

全部通过后，T_long 为 48 个靶点接受时间的最大值；每个长期快照都真实运行到这个共同时间，另存逐靶点诊断。通过诊断只表示有限预算下分布检查通过，不证明唯一稳态或持续振荡，也不将每个细胞标成变化率为零。

公共 RNA 为最后一次 floor(M) 的整数计数。完整连续 G/U/M、参数、网络和随机流来源只留生成／评分侧。关闭逐细胞 64×64 稠密局部导数文件，后续可根据私存 M 和参数按需准确重算，不改变轨迹。学习器只读取白名单中的 RNA、条件和划分。

## 训练与比较

保持之前的 latent Neural ODE（潜变量神经常微分方程）结构族：每基因两个代理状态，64 基因共 128 维；神经网络隐藏宽度 64，局部持续扰动输入，最大 RK4 步长 0.25。没有真实 GRN 掩码、模块标签、真实效率、G/U 或真实方程输入。

固定 4800 次更新、每更新 4 条件／64 细胞、学习率 0.001；六个时间等频覆盖，全基因分布及响应损失，额外靶点权重为零。更新次数相对原 4 训练靶点的 600 次提高八倍，避免 32 靶点只获得八分之一的平均训练覆盖。随机训练种子仍为 20261022；只取最后一次权重，不按测试分数挑模型。

模型仍从基线向前积分到各观测时间；群体分布损失不按细胞行配对，直接通过离散 RK4 运算反传，不是连续伴随算法。本轮只改数据规模／拓扑／扰动覆盖，不同时加入新的 GRN 神经结构、真值约束或稳态惩罚。

比较无响应与仅靶点响应迁移两种基线；分别报告靶点响应、非靶点响应、全基因响应、处理／对照分布、长期误差。非靶点不等于真实下游。新旧网络不同，不能仅比较两次绝对误差便断言扩大规模有效；看同一新数据上相对基线的表现。单网络结果不作网络间显著性结论。

训练后以步长 0.125 重算预测；预先设定最大基因均值差 0.01、最大单预测值差 0.05。失败必须报告，不把检查失败模型当成数值验收成功。当前模型没有经过验证的显式 GRN 提取接口，表达预测成绩不等于恢复完整网络。

## 运行与输出地址

依赖 Python≥3.12、NumPy≥2、PyTorch≥2.5；测试还需 pytest。当前 Mac 使用项目虚拟环境，其他设备可安装 `pip install -e '.[dev]'`；Windows 使用 Ubuntu/WSL，不直接运行含 fcntl 的生成器。CPU 生成不使用 H200；完整训练现按用户选择交由 H200，实际 GPU 训练仍待计算端执行，见[镜像与交付说明](q1-h200-delivery.md)。

项目根目录运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 PYTHONPATH=src \
python -m grn_experiment.q1_generate \
  --config configs/q1-modular-64.json \
  --output data/q1-modular-64-20261023-seed201 --workers 6

PYTHONPATH=src python -m grn_experiment.q1_pilot \
  --dataset data/q1-modular-64-20261023-seed201 \
  --output results/q1-modular-64-20261023-seed20261022 \
  --updates 4800 --seed 20261022 --device cuda --threads 4
```

第二条是 GPU 计算端的直接命令，不在本 Mac 执行完整训练；镜像平台使用交付页的入口及挂载。生成器仅在配置、生成源码、运行时和所有已登记文件校验不变时续跑；不得编辑旧清单去绕过拒绝。训练输出必须是全新目录。

完整原始输出地址：

- `data/q1-modular-64-20261023-seed201/manifest.json`：进度、划分、条件、诊断、文件校验。
- 同目录 `observations/q1/`：289 个公共 RNA 文件。
- 同目录 `private/`：网络、参数、连续状态和来源；不交给学习器。
- `results/q1-modular-64-20261023-seed20261022/`：模型权重、训练计划、逐轮日志、逐条件分数、预测、报告与校验。训练开始前归档实际学习源码。

上面是直接命令的相对输出；本轮给同学的镜像统一输出到 `/output/q1-modular-64-h200-seed20261022/`，内部 `results/` 保存上述结果，外层另有 `run.log` 与 `runtime.json`。**同学只需压缩并回传整个该 run 目录**，不压缩项目或环境。

若同学只负责训练，**只回传这个结果目录**，例如：

```bash
tar -czf q1-modular-64-training-results.tar.gz \
  results/q1-modular-64-20261023-seed20261022/
```

若同学负责重新生成并训练，则再单独压缩 `data/q1-modular-64-20261023-seed201/` 供生成／评分侧核查，不必压缩整个项目和虚拟环境。原始数据、权重、完整预测和真值均受 Git 忽略；GitHub 仅保存代码、配置及诚实的运行摘要。
