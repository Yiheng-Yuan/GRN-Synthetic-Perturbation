# GNW 小网络本机适配验收

历史工具：当前主实验已选择 scMultiSim 持续扰动扩展，GNW 不参与正式数据生成。本文件保留原验收方法，不代表当前实验入口；现行方案见 [主协议](../../docs/protocol/scmultisim-v1.md)。

此工具直接调用官方、未修改的 GNW 3.1.2 Beta Java 程序包，不以项目现有 Python 生成器替代 GNW。只运行固定的 **4 基因、6 有符号边**网络，不生成正式开发/盲测队列，不训练任何模型。

网络含 `G1→G2→G3`、`G1→G3` 前馈环，`G2↔G3` 正反馈，`G3→G4 ┤G3` 负反馈。矩阵约定为 **行＝被调控基因，列＝调控基因**。所有输入模块 `k=0.5,n=1`，基础活性 `0.4`，有符号作用系数 `±0.12`。这些系数不是状态依赖的局部导数。

这次显式设置的 GNW 模块状态活性使产生函数为：

\[
p_i(x)=0.4+\sum_j c_{ij}\frac{x_j}{0.5+x_j},\qquad
F_i(x)=(1-\rho_qd)^{\mathbf1(i=q)}p_i(x)-x_i.
\]

它是 GNW 原生模块模型的一个受控验收特例，不是正式实验必须采用的函数族。所有模块状态活性在 `[0.28,0.64]` 内，故产生率非负；最大调控导数绝对值行和至多 `3×0.12/0.5=0.72<1`，小网络有收缩保证、唯一稳态。此保证不能自动推广到未来任意 GNW 网络。

## 隔离运行

准备 Java 17 运行环境与编译器，以及独立 Python 环境中的 `numpy scipy matplotlib`；无需更改主项目依赖。官方程序包来自固定源码提交 `c5310349f5d5723306585c2bb62aedbdeb70db46`，SHA256：

`b44ce5fcc95d1efc882d0da8a2b0428df4b175fbe4f0a836b4e66e120c08be5b`

```sh
python tools/gnw/run_acceptance.py \
  --java-home /absolute/path/to/jdk/Contents/Home \
  --gnw-jar /absolute/path/to/gnw-3.1.2b.jar \
  --output-dir results/gnw_acceptance_NEW
```

运行器验证程序包校验值，编译 Java 驱动，执行原生 GNW，重复执行检查逐文件一致性，再运行独立验收。必须使用新结果目录，避免覆盖。输出目录被 Git 忽略；不得提交外部运行环境、GNW 程序包或生成数据。

## 时间与扰动

- 关闭翻译层和噪声；当前状态为四个基因的 RNA 丰度，没有隐藏蛋白状态。
- 原生 GNW 的采样步长是整数。使用 `tau=8t`，同时把产生、降解率除以 8；更细参考使用 `tau=16t`，率除以 16。这只是时间单位变换，不改变动力学。
- 每条轨迹先保存共同的扰动前 `t=0` 状态，随后只改变靶基因的最大产生率，始终持续到 `t=8`，不半程恢复。
- 固定效率 `[0.8,0.85,0.9,0.75]`，每靶点剂量 `[0.3,0.5,0.7,0.9]`。另有零剂量和完全敲除解析验收。
- 三个初态各产生一个对照和 16 个扰动分支，加两条特例，总计 **53 条轨迹，每条 65 个时点**。这是配对的合成轨迹，不是 53 个独立生物细胞重复。
- 稳态由独立延长积分获得，用重新计算的 `max(abs(F(x)))` 检查残差，不将 `t=8` 等同于稳态。

## 文件与验收

- `trajectories.csv`：全精度、完整 RNA 轨迹与条件元数据。
- `observed/trajectories.csv`：去除真实效率和实际抑制比例的可见数据视图；其他验收原始文件及 `truth/` 均不应交给未来学习器。
- `refined_trajectories.csv`：细化时间单位/积分容差的对照。
- `edges.csv`：原生网络实际导出的边及符号。
- `probes.csv`：原生固定状态产生率与变化速度，用于独立函数核对。
- `steady_states.csv`：单独求解的稳态、残差和到达时间。
- `truth/parameters.json`：原生 `compileParameters` 导出的参数及输入顺序，仅评分/验收侧使用。
- `truth/jacobian.csv`：局部导数真值，行 target/列 regulator。
- `truth/provenance.json`、`logs/`：来源、版本、文件校验值、原生调用和执行记录。
- `report.json`、`report.md`、图：独立验收与可视化。

Python 从实际导出参数重建 GNW 模块状态概率加权产生率，并用 SciPy 独立积分。验收包括原生与独立变化速度/轨迹一致性、细化精度、初态共享、持续靶点产生项缩放、零剂量、完全敲除指数衰减、非负性、实际边作用、传播、独立稳态和重复执行一致性。未通过不得降低阈值掩盖差异。

通过仅表示此路径能正确导入小网络并生成确定性连续 RNA 轨迹，不证明测序计数真实性、随机过程质量、正式网络可靠性或学习器能够恢复 GRN。
